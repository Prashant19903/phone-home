# Reel / YouTube script: "Maine browser ka homepage hi phone bana diya"

Length: ~45-55 sec (Reel). Language: Hinglish. Keep cuts fast, text on screen for every line.

## Hook (0-3 sec)
Visual: new tab opens, four phones glow one by one.
VO: "Tab kholte hi Instagram, WhatsApp, Reddit, YouTube, sab ek saath, aur sab logged-in."
Text: "Mera browser homepage = 4 phones"

## Problem (3-10 sec)
Visual: quick cuts of switching tabs, tab bar full of tabs.
VO: "Roz 10 tabs kholna, har baar login, har baar switch. Time waste."
Text: "Tabs ki problem"

## Reveal (10-25 sec)
Visual: hover on each phone, focus lift + colour glow, scroll Instagram inside the frame, reply in WhatsApp.
VO: "Isliye maine ek extension banaya. Har app apni phone screen me, seedha homepage par. Hover karo toh Apple TV jaisa glow aata hai."
Text: "Hover = Apple TV style focus"

## Features (25-40 sec)
Visual: + Add app, add YouTube, drag to reorder, Auto size, mascot (turn it on for this part).
VO: "Koi bhi app add karo, drag karke order badlo, size apne aap screen ke hisaab se fit hota hai. Aur ye chhota Builder Bot bhi hai."
Text: "Add apps · Drag · Auto-fit · Builder Bot"

## Honest bit (40-47 sec)
Visual: a site that refuses, then Pop out button.
VO: "Har site frame me nahi chalti, uske liye Pop out button hai. Aur koi data kahin nahi jata, sab tumhare browser me."
Text: "Privacy: no tracking"

## CTA (47-55 sec)
VO: "Ye open source hai. Link bio me, GitHub par. Kaunsa app add karwana hai? Comment karo."
Text: "Open source · Link in bio"

## Caption
Browser ka homepage hi phone bana diya 📱 Instagram, WhatsApp, Reddit, YouTube, sab ek tab me. Open source, link bio me. Kaunsa app chahiye? Comment karo.
